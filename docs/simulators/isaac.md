# Isaac Sim

Render a TwinRobo camera from any USD camera in Isaac Sim. Importing
`twinrobo.plugins.isaac` works without Isaac; its classes need a running `SimulationApp`.
Setup is in the [simulators guide](https://twinrobo.github.io/simulators/#isaac-sim).
